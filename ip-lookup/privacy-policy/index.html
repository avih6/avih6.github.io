1. Overview

IP Lookup is provided by avih6 as a Free utility application. This SERVICE is provided at no cost and is intended for use as is. The application is designed to retrieve public network information and geolocation data based on IP addresses.

By using the Service, there is an agreement to the policies described herein. The application is designed with privacy in mind and does not collect or store any personally identifiable information on private servers.

2. Data Handling & Local Storage

User preferences, such as interface themes and vibration settings, are stored locally on the device using Android's DataStore. This configuration data remains strictly on the device and is never synchronized to external clouds or servers.

3. Technical Data & External Services

To provide network lookup capabilities and display advertisements, the App utilizes third-party providers:

IP Geolocation Service (ipwho.is)

The core functionality of the App relies on an external API provided by ipwho.is. When an IP address is searched, or when the App launches to find the device's public IP, the IP address is transmitted securely (via HTTPS) to the ipwho.is servers to retrieve geolocation data (such as country, city, and ISP). The App does not associate this data with any user identity. For more details on how this service handles data, please review the ipwhois Privacy Policy.

Google AdMob

The App displays advertisements served by Google AdMob. AdMob may process device identifiers (such as the Android Advertising ID) and IP addresses for serving and personalizing advertisements, as well as for ad measurement. For more information on how Google manages advertising data, visit Google's Advertising Policies.

4. Third-Party Service Providers

The app relies on the following third-party service providers:

  • Google Play Services: Core platform support.
  • Google AdMob: Advertisement delivery.
  • ipwho.is: Network intelligence and IP geolocation data.

5. App Permissions

To provide full functionality, IP Lookup requests the following standard capabilities:

  • Internet & Network State: Required to query the geolocation API and load advertisements.
  • Vibrate: Used to provide optional haptic feedback upon successful lookups.
  • Advertising ID (com.google.android.gms.permission.AD_ID): Used by Google AdMob to provide ad measurement.

6. Children’s Privacy

There is no intentional collection of personally identifiable information from children under the age of 13. As no personal identifiers are collected by the app itself, it complies with standard privacy protections for minors.
