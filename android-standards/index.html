avih6 Android Standards

avih6 Android Standards provides workflows for Android app development, release and reporting.

AdMob reporting

Authorized users can retrieve ad requests, matched requests and impressions for a selected app. Google OAuth provides report access, and a private GitHub Actions workflow generates the report. The Privacy Policy describes the data used and how to revoke access.
