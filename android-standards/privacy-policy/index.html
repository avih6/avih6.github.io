1. Overview

This policy covers avih6 Android Standards and its AdMob reporting connection.

2. Authorization

The connection uses Google OAuth with the admob.report scope. Authorization is initiated by the account holder.

3. Data accessed

The workflow reads the publisher account identifier and reporting time zone, and retrieves app and ad unit identifiers, report dates, ad requests, matched requests, impressions, match rate and show rate.

4. Purpose

These data are used to generate and interpret AdMob delivery reports for the requested app.

5. Credentials

The OAuth client credentials and refresh token are stored as a GitHub Actions secret in a private repository and used to obtain access tokens from Google.

6. Report storage

GitHub Actions stores generated reports as private workflow artifacts configured to expire after seven days. People with repository access may be able to retrieve them.

7. Service providers

Google provides authorization and reporting. GitHub runs the workflow and stores its artifacts. When a report is opened in an assistant host, that host processes the report content to answer the request.

8. Website

These pages provide information about the connection. They contain no analytics scripts or forms. The hosting provider may process requests needed to serve the pages.

9. Revoking access and deletion

Revoke the OAuth grant in Google Account settings. Repository administrators can remove the stored secret and report artifacts. Copies downloaded separately are managed where they were saved.

10. Changes

Updates to this policy are posted on this page.

11. Contact

For privacy questions, contact av6development@gmail.com.
