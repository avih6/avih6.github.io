2. Description of Service

My List is an Android application for creating and managing shopping lists. Lists remain on the device until a user chooses to share them. Shared lists synchronize through Firebase for their members.

3. User Accounts & Authentication

The App allows access via Google Sign-In or anonymous guest mode. Google sign-in alone does not upload local-only lists. A list is uploaded when the user explicitly shares it. Users are responsible for maintaining the security of their devices and for activity conducted through their sessions.

4. Shared Groups & Invite Codes

My List allows users to share a list and invite others using a randomly generated invite code. A preview displays the list name and member names before joining. A list can have up to 100 members.

  • Possession of a valid invite code allows a person to request to join. Members can view and update shared-list items according to list permissions and can see member names. The list creator controls whether contributor names and item times are shown.
  • Invite codes should be shared only with intended participants. The list creator can rotate a code, delete a shared list for all members, or make the list private by saving a local copy and removing the shared version.
  • Members can leave while at least two members remain. If the creator leaves, ownership passes to the first remaining admin in the order appointed, or to the first remaining member when no appointed admins remain. The former creator loses access and must be invited again to return.
  • The last member cannot leave an empty group. The creator can delete the list for everyone or make a private copy on the current device.
